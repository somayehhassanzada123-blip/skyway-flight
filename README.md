# SkyWay --- Flight Booking Website

SkyWay is a modern, responsive travel and flight-booking website
concept. It brings flight search, destination discovery, travel deals,
hotel stays, and travel information together in one interface.

**Live Website:**
https://somayehhassanzada123-blip.github.io/skyway-flight/

## Overview

The project is designed to provide visitors with a clear and convenient
way to explore travel options. Its interface uses a clean layout,
destination imagery, and dedicated sections for discovering flights and
travel offers.

## Features

-   **Flight search interface** --- search form with trip types such as
    round trip, one way, and multi-city.
-   **Passenger options** --- controls for adults, children, and
    infants, plus cabin-class selection.
-   **Popular destinations** --- destination highlights with sample
    starting prices.
-   **Flight deals** --- promotional flight cards with route, duration,
    and sample fare information.
-   **Hotels and travel packages** --- featured accommodation and
    holiday package sections.
-   **Booking guidance** --- a simple overview of the steps involved in
    planning a trip.
-   **Account interface** --- login and sign-up interface elements.
-   **Newsletter subscription** --- an area for visitors to subscribe to
    travel updates.
-   **Responsive layout** --- designed to adapt to different screen
    sizes.
-   **Shared navigation and footer** --- consistent site navigation and
    footer content.

> **Note:** Flight fares, hotel listings, reviews, and other travel
> details shown on the website may be demonstration content. Do not
> treat them as live offers or confirmed bookings unless the project is
> connected to verified booking and payment services.

## Pages and Sections

The website navigation includes the following main sections:

-   Home
-   Booking
-   Contact
-   About Us

The home page also includes destination highlights, flight deals, hotels
and packages, frequently asked questions, and newsletter sections.

## Technologies

The project is intended as a front-end website built with:

-   HTML5
-   CSS3
-   JavaScript

## Run Locally

1.  Clone the repository:

    ``` bash
    git clone https://github.com/somayehhassanzada123-blip/skyway-flight.git
    ```

2.  Open the project folder:

    ``` bash
    cd skyway-flight
    ```

3.  Open `index.html` in your browser.

    Alternatively, use the **Live Server** extension in Visual Studio
    Code for local development.
